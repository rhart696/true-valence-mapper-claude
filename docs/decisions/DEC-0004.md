# DEC-0004 — Guided sense-making before generative interpretation

Currency: authoritative · Owner: Richard Hart / ProActive ReSolutions · Created/reviewed: 2026-10-05
Related: SRC-0001, CLM-0003, CLM-0004

Status: accepted direction; branch implementation subject to review.

Problem: Guided sense-making before generative interpretation.

Decision: Prioritize facilitator-supported noticing, evidence, interpretation, uncertainty and action experiments. Defer product generative AI.

Alternatives: AI insights first; visualization only; longitudinal platform first.

Rationale: The user endorsed a reflective behavior-change direction; benefit is still a hypothesis to evaluate.

Consequences and limits: Structural detection may describe reciprocal or asymmetric ratings but must not infer motives, diagnosis or another person's actual mental state.

Evidence/antecedents: SRC-0001, CLM-0003, CLM-0004.

Revisit when: pilot evidence, security assessment or user direction changes the rationale. Supersede this record explicitly; do not rewrite the historical rationale.
