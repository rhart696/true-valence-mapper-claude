# DEC-0006 — Evidence records and lightweight mechanical checks

Currency: authoritative · Owner: Richard Hart / ProActive ReSolutions · Created/reviewed: 2026-10-05
Related: SRC-0001, SRC-0012, SRC-0013

Status: accepted direction; branch implementation subject to review.

Problem: Evidence records and lightweight mechanical checks.

Decision: Maintain docs/governance/registry.json as the machine-readable index; detailed records live at indexed paths. Each substantive change adds an immutable change manifest and validation report.

Alternatives: Require reading every historic document; trust prompts alone; build a database now.

Rationale: Standard-library checks can verify record references and per-change context with no new application dependencies.

Consequences and limits: CI validates structure and traceability only; source quality and contextual adequacy require review. Minor editorial changes can use a documented lightweight path.

Evidence/antecedents: SRC-0001, SRC-0012, SRC-0013.

Revisit when: pilot evidence, security assessment or user direction changes the rationale. Supersede this record explicitly; do not rewrite the historical rationale.
