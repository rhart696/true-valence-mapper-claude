# DEC-0007 — Executable lifecycle and independent human release control

Reviewed: 2026-10-05. Lifecycle: accepted. Owner: Richard Hart; drafted by Codex within current user authorization.

Use stdlib work-package checks, ordered stages, coordinated product/service impacts, exact path coverage and immutable manifests. GitHub required checks/human review are necessary external merge controls. Use real GitHub approval reviews bound to build/config for client release; agents cannot manufacture approval. Alternative: documentation alone (insufficient mechanical enforcement); heavy external PM platform (additional administration). Current connection lacks administration writes, so prepare and verify activation separately. This is an accepted implementation choice within the user-authorized enforcement request, not activated GitHub policy.
