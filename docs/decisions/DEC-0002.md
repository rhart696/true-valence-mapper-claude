# DEC-0002 — Evidence-governed product–service development

Currency: authoritative · Owner: Richard Hart / ProActive ReSolutions · Created/reviewed: 2026-10-05
Related: SRC-0001, SRC-0002, SRC-0014, SRC-0016

Status: accepted direction; branch implementation subject to review.

Problem: Evidence-governed product–service development.

Decision: Adopt EGPSD as an internal working model with one current-state entry point and proportionate traceability.

Alternatives: Ordinary feature backlog only; full certification programme now.

Rationale: The tool and facilitated service need synchronized specifications and visible uncertainties. Standards provide inputs, not automatic proof or a universal best method.

Consequences and limits: Stable records, review dates, requirements and experimental learning; no ISO conformity claim. Governance cannot guarantee that agents understand context.

Evidence/antecedents: SRC-0001, SRC-0002, SRC-0014, SRC-0016.

Revisit when: pilot evidence, security assessment or user direction changes the rationale. Supersede this record explicitly; do not rewrite the historical rationale.
