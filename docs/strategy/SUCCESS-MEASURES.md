# Pilot success and learning measures

Currency: authoritative · Owner: Richard Hart / ProActive ReSolutions · Created/reviewed: 2026-10-05
Related: See START-HERE and registry.

| Domain | Session question / measure | Interpretation |
|---|---|---|
| Representation | Did this fairly represent your current experience? What differed? | Participant perception, not objective accuracy |
| Insight | What did you articulate that was previously implicit? | Include no-insight cases |
| Utility | What, if anything, will you do differently? | Intention is not behavior |
| Friction | Where did the tool interrupt the conversation? Time/errors/completion | Context and facilitator matter |
| Follow-up | At 1–3 weeks: what did you actually do and what happened? | Self-report; no causal attribution |
| Reuse | Would you choose this again, and in what context? | Preference, not efficacy |
| Harm/burden | Any discomfort, pressure, misinterpretation or adverse consequences? | Review promptly; may suspend pilot |

Use descriptive counts and medians/ranges where useful, alongside contextual qualitative findings. Repeated uses are nested within people/facilitators. Set feasibility thresholds before pilot enrollment with sponsor/facilitators; no arbitrary evidence-based target invented here. All favorable and unfavorable observations enter review.
