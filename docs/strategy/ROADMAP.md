# Evidence-governed roadmap

Currency: authoritative · Owner: Richard Hart / ProActive ReSolutions · Created/reviewed: 2026-10-05
Related: See START-HERE and registry.

| Phase | Deliverable | Exit evidence |
|---|---|---|
| 0 — convergence/governance | Canonical direction, preserved lineage, records, product/service specs, context checks | Phase 0 checks and reviewed paired PRs; no runtime-readiness claim |
| 1 — executive pilot build | Dependency, authorization, persistence, privacy and accessibility remediation; evidence/inference/action fields; facilitator guide and report | Passing release gates at a named build; human release decision |
| 2 — developmental pilot | Proposed 3–4 facilitators, 8–12 executives, 15–25 uses | Authorized protocol, observations, follow-up and findings including negative cases |
| 3 — guided sense-making refinement | Only refinements justified by pilot; descriptive patterns and prompts | Linked decisions and measured burden/utility; generative AI not required |
| 4 — engagement tracking | Contextual snapshots, comparison, action follow-up | Schema/versioning, deletion and longitudinal usefulness evidence |
| 5 — assisted intelligence | Consider source-aware prompts/summaries/hypotheses | Adequate empirical rationale, AI risk assessment and human interpretation boundaries |

Sequence within Phase 1: REQ-0009 dependency baseline; REQ-0006 persistence; REQ-0007/8 sharing and retention; REQ-0003/4/5 inquiry and action; REQ-0010 accessibility/export; REQ-0011 pilot protocol. Sensitive cloud work may run alongside a local synthetic-data prototype, but client pilot remains blocked.

Guided inquiry fields belong in the first usable pilot; Phase 3 is evidence-led refinement, not a reason to postpone the intended behavior-change loop. Dates/effort estimates require technical remediation scope and available facilitator capacity, so no invented delivery date.
