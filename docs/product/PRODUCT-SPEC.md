# ProActive executive pilot product specification

Currency: authoritative · Owner: Richard Hart / ProActive ReSolutions · Created/reviewed: 2026-10-05
Related: See START-HERE and registry.

Retain radial map, bidirectional ratings, notes, local save, demo and PDF/PNG where verified. Keep technical maximum 25 during Phase 0; suggest starting with 8–12 relevant relationships as an unvalidated facilitation default. Never calculate average trust, classify people or infer between-person network structure from a hub-only map.

Map: state purpose/context and framing; add pseudonyms; independent outbound and inferred inbound categories High/Moderate/Low/Not yet considered. Preserve serialized medium/unscored values during initial migration. Exact starting question remains about a problem with this person (DEC-0003); a broader question is an explicit future experimental variant.

Notice: ask 'What do you notice?' before showing optional descriptive reciprocal high/low, asymmetry or unconsidered labels. Both categories must be considered before classifying reciprocal/asymmetric patterns. No causal labels, isolation/cluster claims or central-dependency analysis from absent edges.

Make sense: selected relationship has optional observation, interpretation, confidence in inference, alternative explanation and other-person perspective. These are user reports, not software findings. Provide prompts that invite evidence and disagreement; allow skip.

Act: choose at most a suggested one to three priorities; desired shift, hypothesis, experiment/action, expectation, surprise, intended date and outcome. No coercion to test by confronting someone.

Save/export: explicit local persistence explanation and error recovery; exports include context, date, framing and selected notes/actions with user control. Optional cloud sharing must meet REQ-0007/8 before pilot. Research collection requires separate mode and consent; no implicit analytics.

Acceptance and verification live in REQ-0003 through REQ-0011. This is the intended pilot specification, not an implementation inventory.
